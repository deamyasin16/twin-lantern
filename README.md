Twin Lantern is a spot the difference game: two harbour towns drawn side by side, almost alike. Find every difference before the clock runs out, across three sets that grow subtler, with a hint ring, a miss penalty and a counter of how many remain.

## Run it

```sh
node serve.ts
```
